PredictionApi

Módulo 2 · API + LLM
Dois caminhos: predição síncrona em milissegundos e laudo via LLM desacoplado por fila — a API nunca bloqueia esperando a GPU.
ms vs 60 s
Classificador responde na hora; a LLM roda em background — sem timeout no browser.
Fila = escala
Redis absorve picos de requisições; workers podem ser adicionados horizontalmente.
GPU protegida
Worker consome 1 tarefa por vez, respeitando a GPU única do Ollama.
Resiliência
Retries automáticos com backoff se a LLM falhar; API segue disponível.

Front

Módulo 3 · Interface Clínica
O médico vê o diagnóstico imediatamente; o laudo chega depois por polling — a lentidão da LLM nunca aparece na tela.
